# 📚 Kütüphane Yönetim Sistemi (Tkinter GUI)

Bu proje, basit bir **kütüphane yönetim sistemi** uygulamasıdır. Python ile geliştirilmiş ve grafiksel arayüz için **Tkinter** kullanılmıştır. Kullanıcılar kitapları ve üyeleri yönetebilir, kitap ödünç verme ve iade işlemlerini gerçekleştirebilir.

## 🧩 Özellikler

- 📖 Kitap ekleme, silme ve listeleme
- 👤 Üye ekleme, silme ve listeleme
- 🔄 Kitap ödünç verme ve iade alma
- 📊 Rapor ekranı ile genel istatistiklerin görüntülenmesi

## 🛠️ Kullanılan Teknolojiler

- Python 3
- Tkinter (GUI için)
- OOP (Nesne Tabanlı Programlama)
- Basit veri yapıları (sözlükler, listeler)
